# Lyncit AI

Lyncit AI is a powerful tool designed to help recruiters hire candidates efficiently. Leveraging the power of AI, Lyncit AI generates tailored interview questions based on the recruiter's requirements and dynamically adapts follow-up questions based on the candidate's responses. This ensures a streamlined and effective hiring process.

## Features



- **AI-Powered Question Generation**: Automatically generates interview questions based on job requirements.
- **Dynamic Follow-Up Questions**: Adapts follow-up questions based on candidate responses.
- **Efficient Hiring Process**: Saves time and effort for recruiters by automating the interview process.



## Getting Started

Follow these steps to set up and run Lyncit AI on your local machine.

### Prerequisites

- Node.js (v18 or higher)
- Yarn (v1.22 or higher)

### Installation

1. Install dependencies:
   ```bash
   yarn install

### Running the Application   

1. Start the development server:
   ```bash
   yarn start

   This will start the application in development mode. Open your browser and navigate to http://localhost:3000 to view the app.

2. Build the application for production:
   ```bash
   yarn build

   This will create an optimized production build of the application.

3. Start the production server:
   ```bash
   yarn start

   This will serve the production build of the application.

### Scripts

- build: Builds the project for production deployment.
- start: Runs the production server.
